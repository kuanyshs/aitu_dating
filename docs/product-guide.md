## 1. Что такое Aitu Dating

Aitu Dating — закрытое verified-сообщество для знакомств. Здесь знакомятся не свайпом по фотографиям, а через разговор:

- **пост** — мысль, история или наблюдение;
- **вопрос** сообществу;
- **план встречи** один на один в публичном месте.

Люди читают друг друга, отвечают, подписываются и договариваются о встрече. Переписка возможна только из понятного контекста.

Три принципа клуба:

| Принцип | Что это значит |
|---|---|
| Aitu Passport | Каждый участник подтверждает личность через Aitu Passport. Анонимных анкет нет: имя, возраст, пол и город берутся из Passport и не редактируются. |
| Первая встреча — в публичном месте | План встречи нельзя опубликовать, не подтвердив «Это публичное место». |
| Жалобы и блокировка | Любого можно заблокировать или пожаловаться на него. Жалобы разбирает модерация, нарушителей ограничивают. |

Доступ к сообществу даёт **membership**: платный (1, 3, 6 или 12 месяцев) или «Бесплатный verified» на 12 месяцев. Платить за сообщения, реакции или планы отдельно не нужно — уровень доступа один.

## 2. Как открыть прототип

**По ссылке (проще всего).** Откройте [прототип](https://claude.ai/artifact/FijUEgAT17isgQ5dx13HFT) в браузере телефона или компьютера, войдя в аккаунт claude.ai. Ссылка приватная: другим людям доступ выдаётся через меню Share на странице.

- На телефоне страницу можно добавить на главный экран: в iPhone — «Поделиться» → «На экран „Домой"», в Android — меню ⋮ → «Добавить на главный экран».
- На компьютере удобнее сузить окно или включить в DevTools вид телефона (390×844).

**Локально.** Установите Git и Node.js 22, затем:

```bash
git clone https://github.com/kuanyshs/aitu_dating.git
cd aitu_dating
git checkout claude/sweet-hypatia-gwvlba
corepack enable
pnpm install
pnpm web
```

Приложение откроется на `http://localhost:8081`. Для Expo Go на телефоне используйте `pnpm start` и отсканируйте QR-код. Подробности — в README.

**Тема.** Светлая или тёмная, по умолчанию следует настройке телефона. Изменить можно в «Настройки → Оформление».

## 3. Кто есть кто: роли и доступ

| Роль | Кто это |
|---|---|
| **Гость** | Открыл приложение и ещё не вступил (или вышел в режим preview). |
| **Вступающий** | Гость, который проходит вступление: Passport → правила → membership → карточка → анкета. |
| **Участник** | Прошёл вступление, membership активен. Полный доступ. |
| **Участник с истёкшим membership** | Карточка сохранилась, но срок доступа кончился. Читает и управляет своим, социальные действия ведут в «Продление». |
| **Участник под ограничением** | Модерация ограничила доступ. Видит только экран ограничения. |
| **Модератор** | Участник с ролью модератора: дополнительно разбирает жалобы. |

Что доступно каждой роли:

| Действие | Гость | Участник | Истёкший | Под ограничением |
|---|---|---|---|---|
| Читать ленту, посты, обсуждения, планы | Да, люди в безопасном виде | Да | Да, люди в безопасном виде | Нет |
| Видеть имена, фото и карточки других | Нет | Да | Нет | Нет |
| Лайки, ответы, репосты | Ведут во вступление | Да | Ведут в «Продление» | Нет |
| Публиковать посты, вопросы, цитаты | Ведут во вступление | Да | Ведут в «Продление» | Нет |
| Создавать планы и откликаться | Ведут во вступление | Да | Ведут в «Продление» | Нет |
| Открывать чужие профили | Ведут во вступление | Да | Безопасный вид и «Продлить» | Нет |
| Подписываться | Нет | Да | Нет | Нет |
| Чаты | Нет | Читать и писать | Только читать | Нет |
| Поиск людей | Нет | Да | Ведёт в «Продление» | Нет |
| Поиск публикаций и планов | Да | Да | Да | Нет |
| Своя карточка: смотреть и редактировать | — | Да | Да | Нет |
| Удалять своё | — | Да | Да | Нет |
| Пожаловаться | Да, анонимно | Да | Да | Нет |
| Заблокировать | Нет | Да | Да | Нет |
| «Активность» | Приглашение вступить | Да | Да, люди в безопасном виде | Нет |

**Безопасный вид** — пол, возраст, город и один общий нейтральный силуэт вместо аватара. Имя, фото, интересы, намерение и анкету гость и участник с истёкшим membership не получают вообще: эти данные не уходят с «сервера», а не просто скрыты в интерфейсе.

**Полный вид** — имя, аватар, отметка о проверке, ссылка на профиль.

## 4. Навигация

Внизу плавающая панель из пяти вкладок:

| Вкладка | Что там |
|---|---|
| Главная | Лента сообщества с фильтрами |
| Поиск | Люди, публикации, планы |
| Создать (＋) | У участника сразу открывает редактор поста |
| Активность (♡) | Что произошло вокруг вас; точка на значке, пока есть новое |
| Профиль | Своя карточка, публикации, встречи, настройки |

**Шапка Главной:**

- слева «☰» — меню;
- по центру «aitu dating» и подпись «preview сообщества» у гостя или «verified conversations» у участника;
- справа у гостя «Вступить» (или «Войти», если у текущей личности уже есть карточка), у участника — «Сообщения» со счётчиком непрочитанных, у истёкшего — «Продлить».

**Меню Главной:**

- О продукте;
- Настройки;
- Безопасность;
- участнику: Сообщения, Membership, Активность;
- модератору: Модерация;
- участнику: «Выйти» — переход в режим preview.

Полноэкранные экраны (пост, профиль, план, чаты) закрываются стрелкой «‹». Листы (настройки, безопасность, жалоба, О продукте, Membership) — крестиком.

## 5. Инструкция по шагам

### 5.1. Первый запуск

1. Приложение открывается на Главной в режиме гостя.
2. Листайте ленту. У авторов видны только пол, возраст и город.
3. Переключайте фильтры «Для тебя», «Популярное», «В городе» и «Планы». В «В городе» город выбирается, по умолчанию Алматы.
4. Попробуйте поставить лайк — откроется вступление. Без него социальные действия недоступны, и приложение объясняет почему.

### 5.2. Вступление

1. Нажмите «Вступить» в шапке Главной.
2. **Aitu Passport.** Выберите личность: Айдана, Тимур или Мадина (в прототипе это демо-личности). Имя, возраст, пол и город показаны только для чтения.
3. **Правила клуба.** Прочитайте и отметьте «Я прочитал(а) правила и принимаю их».
4. **Membership.** Выберите ровно один вариант: платный период (1 / 3 / 6 / 12 месяцев) или «Бесплатный verified».
5. **Оплата (демо)** — только для платного периода. Нажмите «Оплатить (демо)»: реквизиты не запрашиваются, деньги не списываются. Если оплата «не прошла», нажмите «Повторить оплату» — повтор не спишет дважды.
6. **Карточка.**
   - «О себе» — от 1 до 160 символов;
   - интересы — от 1 до 5;
   - стиль общения.
7. **Анкета.** 7 вопросов, в каждом один вариант, прогресс N/7.
8. Нажмите «Создать карточку». Вы — участник: в ленте появляются имена, а в Профиле — ваша карточка.

Вступление можно закрыть на любом шаге. При следующем «Вступить» оно продолжится с того же места.

### 5.3. Лента

- **Для тебя** — посты по вашим темам, от тех, на кого вы подписаны, и свежие.
- **Популярное** — по активности.
- **В городе** — посты из выбранного города.
- **Планы** — открытые планы встреч.
- **Подписки** — только от тех, на кого вы подписаны. Только у участника.

Нажмите на пост, чтобы открыть его целиком. Нажмите на 💬 — откроется пост сразу с полем ответа. Имя или аватар автора открывают его профиль.

### 5.4. Пост и обсуждение

1. Откройте пост: текст целиком, темы, карточка плана или цитата, если есть.
2. Ниже «Ответы · N» и переключатель «Популярные / Новые».
3. Ответы под комментарием соединены тонкой линией.
4. Внизу «Добавить ответ…» открывает экран «Ответ»: до 360 символов, «Ответить» неактивна, пока текст пуст.
5. «Ответить» у комментария открывает ответ ему, например «Ответить Арману…». У ответа второго уровня кнопки «Ответить» нет: глубже двух уровней ветка не идёт.
6. «•••» у чужого поста или комментария: «Пожаловаться», «Заблокировать автора». У своего — «Удалить» с подтверждением.

### 5.5. Лайк, репост, цитата

- ♡ — лайк поста или комментария, повторное нажатие снимает.
- ⟲ — репост чужого поста, повторное нажатие отменяет. Свой пост репостнуть нельзя.
- ❝ «Цитировать» — открывает редактор с карточкой цитируемого поста.

### 5.6. Создание поста, вопроса, цитаты

1. Вкладка «Создать» (＋) сразу открывает редактор.
2. Выберите «Пост» или «Вопрос». «План» ведёт в форму плана.
3. Выберите до 4 тем (необязательно).
4. Напишите текст, до 1000 символов.
5. «Опубликовать» → тост «Опубликовано», и ваш пост первым в ленте «Для тебя».

Если закрыть редактор с текстом, приложение спросит: «Сохранить черновик» или «Удалить». В следующий раз черновик восстановится. Если вы открыли редактор для другой цели, например цитаты, приложение предложит «Продолжить черновик» или «Начать заново».

Открытая по ссылке вкладка «Создать» показывает выбор: «Пост — мысль, история или наблюдение», «Вопрос — ответы придут в комментариях», «План — встреча один на один в публичном месте».

### 5.7. Свой профиль

- **Карточка:** имя, возраст, город, отметка о проверке, «О себе», намерение, интересы, стиль общения, ответы анкеты, статус membership.
- **Счётчики** публикаций, подписчиков и подписок. Нажатие на счётчик открывает список.
- **Мои публикации** — открыть пост и удалить через «•••» на его экране.
- **Встречи:** «Мои планы» и «Мои отклики».
- **«Редактировать карточку»** — меняются «О себе», намерение, интересы и стиль общения. Данные Passport и ответы анкеты не редактируются. Если уйти с несохранёнными изменениями, приложение спросит «Отменить изменения?».
- **Шестерёнка** — Настройки. **«Выйти»** — режим preview.

### 5.8. Чужой профиль и подписка

1. Нажмите на имя или аватар автора в ленте, посте, комментарии, поиске или списке подписок.
2. В профиле:
   - карточка и счётчики;
   - публикации;
   - «Подписаться», после нажатия — «Вы подписаны»; повторное нажатие отписывает;
   - метка «Взаимная подписка», если вы подписаны друг на друга;
   - при взаимной подписке — кнопка «Написать»;
   - «•••»: пожаловаться или заблокировать.

### 5.9. Поиск

1. Вкладка «Поиск», сегменты «Люди / Публикации / Планы».
2. **Люди:** по имени, «О себе» и интересам; фильтры — город, интересы, намерение. Без текста показываются участники вашего города.
3. **Публикации:** по тексту (от 2 символов) и темам.
4. **Планы:** по описанию; фильтры — город, цель, формат. Ближайшие первыми.

### 5.10. План встречи

**Создать:**

1. «Создать» → «План» или чип «План» в редакторе.
2. Заполните:
   - город (по умолчанию ваш);
   - дату — на 14 дней вперёд;
   - время — шаг 30 минут, сегодня только будущее;
   - формат;
   - длительность — 30, 60, 90 или 120 минут;
   - цель;
   - кто платит;
   - место с галочкой «Это публичное место»;
   - описание до 500 символов и до 4 тем.
3. «Опубликовать». План появится в ленте «Планы» и в «Мои планы».

**Откликнуться (чужой план):**

1. Откройте план из ленты, поиска или профиля. Место видно только активным участникам.
2. «Откликнуться», сообщение до 360 символов необязательно.
3. Ваш статус: «Ждёт ответа», «Встреча договорена» или «Автор выбрал другой вариант».
4. «Отозвать», пока отклик ждёт ответа. После отзыва можно откликнуться снова.

**Решить (свой план):**

1. На экране плана — «Отклики», ожидающие сверху. В ленте на вашем плане виден счётчик ожидающих.
2. «Отклонить» — без подтверждения. «Принять» — с подтверждением.
3. После принятия план становится **Встречей**: остальные ожидающие отклоняются автоматически, у обоих появляется «Встреча договорена» и кнопка «Написать».
4. «•••» → «Закрыть набор» (новых откликов не будет, ожидающие ещё можно решить) или «Отменить план» (с подтверждением, доступно и после договорённости).

### 5.11. Сообщения (контекстные чаты)

1. **Начать чат** можно только из контекста:
   - «•••» у чужого комментария → «Написать»;
   - чужой профиль при взаимной подписке → «Написать»;
   - договорённая встреча → «Написать» у обоих.
2. **Список чатов** — кнопка «Сообщения» на Главной или пункт меню. У каждого чата видны собеседник, контекст одной строкой («Из комментария», «Взаимная подписка», «Встреча: …»), последнее сообщение и число непрочитанных.
3. **В чате:**
   - текст до 1000 символов;
   - статусы «Отправлено» и «Прочитано»;
   - «Показать ранние» для длинной истории.
4. Если сообщение не ушло, оно остаётся с пометкой и «Повторить».
5. «•••» в чате: пожаловаться или заблокировать. После блокировки чат исчезает у обоих.

### 5.12. Активность

1. Вкладка «Активность». Точка на значке — есть новые события.
2. **Категории:** Все, Подписки, Разговоры, Реакции, Планы, Системные.
3. Новые события помечены точкой и выделены. Нажатие на событие открывает пост, план, профиль человека или продление.

### 5.13. Жалоба и блокировка

**Пожаловаться:**

1. «•••» у поста, комментария, профиля, плана или в чате → «Пожаловаться».
2. Выберите причину. Пояснение обязательно только для «Другое».
3. «Отправить» → «Жалоба отправлена» с кнопками «Готово» и «Заблокировать [автора]».
4. Статус и итог — в «Безопасность → Мои жалобы».

**Заблокировать:**

1. «•••» → «Заблокировать [Имя]?» → подтвердить.
2. Снять блокировку — «Безопасность → Заблокированные → Разблокировать».

**Экран «Безопасность»** (меню Главной): советы для первой встречи, «Заблокированные», «Мои жалобы», «Обратиться в поддержку». Гость видит только советы и поддержку.

### 5.14. Модерация (роль модератора)

1. Включите роль в демо-панели. В меню Главной появится «Модерация».
2. Вкладки «Новые», «На рассмотрении», «Решённые». Открытая жалоба переходит «на рассмотрение».
3. Решения:
   - «Отклонить» — без последствий;
   - «Удалить контент» — пост станет «Публикация недоступна», комментарий с ответами — «Комментарий удалён»;
   - «Ограничить участника».
4. Решение закрывает все открытые жалобы на ту же цель, и заявитель видит итог в «Моих жалобах».

### 5.15. Membership и продление

1. Меню Главной → «Membership»: тариф, период, начало, окончание, статус, сколько дней осталось.
2. «Продлить» → выбор периода → оплата (демо), анкету проходить заново не нужно.
3. Когда до окончания остаётся неделя, в «Активности» появляется событие «Membership скоро закончится».
4. После истечения на Главной и в Профиле появляется призыв «Продлить membership».

### 5.16. Выйти и войти

- «Выйти» (Профиль или меню Главной) — режим preview. Карточка, membership, публикации и черновики сохраняются.
- В шапке Главной вместо «Вступить» появится «Войти»: возврат в тот же режим без анкеты.

### 5.17. Настройки

- «Оформление» — Системная, Светлая или Тёмная. Выбор сохраняется.
- В демо-сборке здесь же Demo controls (см. раздел 9).

## 6. Как работают механики

### 6.1. Ленты

| Фильтр | Кто видит | Как формируется |
|---|---|---|
| Для тебя | Все | Совпадение тем с профилем, бонус за подписку, свежесть. Свой новый пост — первым у автора в течение 24 часов. |
| Популярное | Все | Реакции + 2 × репосты + комментарии. |
| В городе | Все | Для постов-планов — город плана, для остальных — город автора. По умолчанию — свой город или Алматы. |
| Планы | Все | Посты-планы со статусом «открыт» или «встреча договорена»; прошедшие не показываются. |
| Подписки | Участник | Только те, на кого подписан. |

Из всех лент исключены заблокированные (в обе стороны), участники под ограничением и удалённые посты.

### 6.2. Обсуждение

- Два уровня: **комментарий** к посту и **ответ** на комментарий. Ответ на ответ невозможен.
- **«Популярные»** — комментарии с большим числом лайков выше, при равенстве новые выше. **«Новые»** — по времени. Ответы внутри ветки — от старых к новым.
- Комментарии подгружаются по 10, ответы приходят вместе со своим комментарием.
- **Удаление своего комментария:**
  - если на него отвечали — на его месте «Комментарий удалён», ответы остаются;
  - если нет — исчезает.

  Удалённое не входит в счётчик «Ответы · N».
- **Комментарий заблокированного человека,** на который отвечали другие, показывается как «Комментарий скрыт».
- Редактирования нет: реплику можно удалить и написать заново.

### 6.3. Репост и цитата

- **Репост** — отметить чужой пост и увеличить его счётчик. Свой репостнуть нельзя.
- **Цитата** — новый пост со своим текстом и карточкой цитируемого. Цитировать можно и своё, и план, и цитату; показывается один уровень вложенности.
- Если оригинал удалили или скрыли, в цитате появится «Публикация недоступна».

### 6.4. Черновик

- Один черновик на человека: тип, текст, темы и цитируемый пост.
- Сохраняется только по выбору при закрытии редактора, очищается после публикации.
- «Выйти» черновик не стирает, «Сбросить демо» — стирает.

### 6.5. Подписка

- Подписаться можно на любого видимого участника, кроме себя.
- **Взаимная подписка** даёт метку в профиле и право начать чат.
- Блокировка снимает подписки в обе стороны, разблокировка их не восстанавливает.

### 6.6. Поиск

- Без учёта регистра, «ё» считается как «е».
- **Люди:** сначала те, у кого имя начинается с запроса, дальше по алфавиту.
- **Публикации:** новые первыми; запрос короче 2 символов не принимается.
- **Планы:** только открытые будущие, ближайшие первыми; гостю без точного места.
- В выдаче нет заблокированных, участников под ограничением и вас самих.

### 6.7. Планы и встречи

- План — только **один на один**, без групп и вместимости.
- Не больше **3 открытых будущих планов** на человека. Четвёртый не опубликуется, и приложение объяснит почему.
- **Статусы:**

| Статус | Что значит |
|---|---|
| Открыт (без метки) | Принимает отклики |
| Встреча договорена | Принят один отклик; остальные ожидающие отклонены автоматически |
| Набор закрыт | Новых откликов нет, ожидающие ещё можно решить |
| Отменён | Ожидающие отклики отклоняются |
| Прошёл | Время начала наступило; считается автоматически, отклики не принимаются |

- **Место** видят только активные участники. **Число ожидающих откликов** видит только автор.
- Заблокированный человек не видит ваш план, а вы — его.

### 6.8. Отклики

- Откликается только активный участник, не на свой план и только на открытый будущий.
- На один план у человека один действующий отклик: повторная отправка вернёт тот же.
- **Жизненный цикл:** «ждёт ответа» → «принят» или «отклонён»; «отозван» — по желанию откликнувшегося, после этого можно откликнуться снова.
- Принять можно только один отклик, отменить принятие нельзя.

### 6.9. Контекстный чат

- **Один чат на пару людей.** «Написать» из любого места открывает существующий чат, а не создаёт новый. Чат помнит контекст, с которого начался.
- **Условия открытия:**
  - чужой видимый комментарий;
  - взаимная подписка;
  - принятый отклик — только для его двух участников.
- Только текст. В демо собеседник не отвечает.
- Открытие чата отмечает сообщения прочитанными, у собеседника появится «Прочитано».
- Участник с истёкшим membership читает чаты, а вместо поля ввода видит «Продлить».
- Блокировка или ограничение собеседника скрывает чат у обоих.

### 6.10. Активность

События собираются из данных и отдельно не хранятся:

| Событие | Категория |
|---|---|
| Подписка на вас | Подписки |
| Комментарий к вашей публикации | Разговоры |
| Ответ на ваш комментарий | Разговоры |
| Отметка «нравится» вашей публикации | Реакции |
| Репост вашей публикации | Реакции |
| Отклик на ваш план | Планы |
| Ваш отклик принят — встреча договорена | Планы |
| Автор выбрал другой вариант | Планы |
| Membership скоро закончится (за 7 дней) | Системные |

- Сообщения в «Активность» не попадают: они в чатах.
- **Открытие вкладки** отмечает всё просмотренным, и точка на значке гаснет. Пока вы на вкладке, «новым» остаётся всё, что пришло после прошлого просмотра, в любой категории. При следующем заходе прежние события уже без меток.
- От заблокированных и скрытых людей событий нет.

### 6.11. Блокировка

Действует в обе стороны:

| Где | Эффект |
|---|---|
| Ленты и профиль | Посты скрыты |
| Экран поста | «Публикация недоступна» |
| Профиль человека | «Профиль недоступен» |
| Комментарии | Скрыты; корневой с чужими ответами — «Комментарий скрыт» |
| Цитаты его постов | «Публикация недоступна» |
| Планы | Не видны, откликнуться нельзя |
| Чаты | Исчезают, новый начать нельзя |
| Подписки | Снимаются |

Счётчики реакций и комментариев не пересчитываются.

### 6.12. Жалобы

- Цели: пост, комментарий, профиль, план, сообщение.
- Повторная жалоба на ту же цель не создаёт новую: появляется «Вы уже пожаловались — жалоба на рассмотрении».
- Жаловаться на своё нельзя.
- До решения модератора контент не скрывается.
- **Итоги** в «Моих жалобах»: «Отклонена», «Контент удалён», «Участник ограничен».

### 6.13. Ограничение

Решение модерации. Человек видит экран «Доступ ограничен» с объяснением, правилами клуба и поддержкой. Его публикации скрыты от всех, профиль показывается как «Профиль недоступен».

- **Мгновенный отклик.** Лайк, репост и подписка обновляются сразу и откатываются с тостом, если действие не прошло.
- **Offline.** Лента показывает последнее загруженное с баннером «Нет сети», действия дают ошибку с «Повторить».
- **У каждого экрана есть все состояния:** загрузка (скелетон), пустое состояние с объяснением, ошибка с «Повторить», «Публикация недоступна» или «Профиль недоступен» для удалённого или скрытого.

## 10. Ограничения прототипа и частые вопросы

**Почему другой человек не видит мой пост?**
Все данные хранятся в вашем браузере, сервера пока нет. Каждый видит свою копию демо-сообщества.

**Почему у моей личности пустые чаты и «Активность»?**
Айдана, Тимур и Мадина — новые люди. Чаты и события появятся, когда с ними начнут взаимодействовать: подпишутся, ответят, откликнутся. Это можно сделать за другую личность через демо-панель.

**Это настоящий Aitu Passport и настоящая оплата?**
Нет, обе интеграции имитированы. Подключение — следующий этап, вместе с бэкендом.

**Почему нет фото?**
Аватары синтетические, загрузка фото появится с бэкендом.

**Где push-уведомления?**
Пока только точка на «Активности» и счётчик сообщений внутри приложения.

**Почему «Обратиться в поддержку» пишет «Скоро»?**
Поддержка появится вместе с бэкендом.

**Почему после перезагрузки я на Главной?**
Так работает версия по ссылке: она всегда стартует с Главной. Данные при этом не теряются.

**Как начать всё заново?**
«Профиль → Настройки → Demo controls → Сбросить демо».

Нет и пока не планируется:

- редактирование опубликованного;
- медиа в постах и чатах;
- упоминания через @;
- групповые чаты и групповые встречи;
- история оплат;
- настройки уведомлений;
- свайпы.
