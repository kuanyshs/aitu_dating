## Решения

### Ответы владельца на противоречия v4

- Неверифицированный пользователь **не пишет** в чаты. Вместо этого ему предлагают пройти верификацию.
- Верифицированный пользователь с истёкшей подпиской старые чаты **только читает**.

### Решения, принятые по ходу (подробно — в спеках)

- **Фильтр.**
  - Темп, первая встреча, границы и стиль общения из фильтра убраны: v4 их не называет. Они по-прежнему поднимают в «Поиске» похожих людей.
  - Условия по встречам не скрывают обычные посты.
  - Свой пост за последние сутки стоит первым в «Поиске» при любом фильтре.
- **Встречи в лентах.** Показываются только открытые. Закрытые, договорённые, отменённые, прошедшие и удалённые остаются в профиле, «Моих встречах», чатах и уведомлениях.
- **«Сгенерировано с ИИ».** Отметку ставит приложение по метаданным исходного файла: тип источника IPTC, текстовые блоки Stable Diffusion и ComfyUI, имя генератора в Software/CreatorTool. Если метаданные стёрты, подписи не будет. Настоящий сервер повторит проверку по оригиналу.
- **Удаление встречи.** Встреча удаляется вместе с её постом. Ожидающие запросы отклоняются, в «Моих встречах» и «Моих запросах» она остаётся со статусом «Удалена».
- **Голосовые.** До 60 секунд и 2 МБ, запись через микрофон браузера.
- **Чат пары.** Создаётся уже при отправке запроса на встречу, а не только после принятия.
- **Уведомление об отмене.** Отмена встречи приходит одним «Встреча отменена», без лишнего «Запрос отклонён».
- **Безопасные фото.** Размытую копию в прототипе делает приложение при загрузке. В бэкенде её будет делать сервер.
- **Ссылка на встречу.** Ссылка — адрес приложения с `/meeting/<id>`; при запуске из файла — `aitudating://meeting/<id>`.

## Известные ограничения прототипа

- **Aitu Passport и оплата** подключаются на этапе бэкенда; в прототипе их шаги проходят без реальных данных.
- **Демо-сообщество локальное.** Ответ собеседника показывается демо-кнопкой «Входящее сообщение» или входом за другую личность.
- **Системное меню «Поделиться»** есть в мобильных браузерах. В настольном браузере без него ссылка копируется.
- **Push-уведомлений в V1 нет.**
- **Правила клуба** — черновик, финальный текст утвердит юрист.

## Что дальше: бэкенд

Предварительные решения прежние: облако в Казахстане, TypeScript + PostgreSQL на тех же контрактах, Aitu Passport, поток событий для сообщений.

К ним добавляются:

- хранилище медиа для фото и голосовых;
- генерация размытых копий и проверка «Сгенерировано с ИИ» на сервере;
- платёжный провайдер к запуску;
- обновление справочника КАТО при новых редакциях классификатора.
