# Национальности

`bns-ethnicities-2026-01-01.csv` — перечень этносов из публикации Бюро национальной статистики АСПИР РК «Численность населения Республики Казахстан по отдельным этносам на начало 2026 года» (опубликовано 27.03.2026, серия 18 «Демографическая статистика»):
https://stat.gov.kz/ru/publication/spreadsheets/?name=18633 (лист «РК», таблица 1).

Колонки: `code` — код этноса БНС, `name` — название, `population_2026` — численность на 01.01.2026.

Из этого перечня приложение строит справочник национальностей анкеты (`src/catalogs/nationalities.ts`): все этносы в порядке численности, «Другие национальности» становятся вариантом «Другая национальность», строка «Не указавшие» не используется — в анкете национальность выбирают обязательно.
